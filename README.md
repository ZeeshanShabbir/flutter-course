## How to Use

### 1. Clone the repo

```bash
git clone <repo-url>
cd flutter-course-d4wee
```

### 2. Stay up to date

```bash
git pull
```

Run this before every class to get newly released code.

### 3. Open a part

Each `pXX-*` folder is self-contained. Open it in your editor and follow the
`README.md` inside for setup and run instructions.
